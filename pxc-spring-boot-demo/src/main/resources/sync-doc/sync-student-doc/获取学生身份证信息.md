# 获取学生身份证信息

## 基本信息
- **接口名称**：获取学生身份证信息
- **接口描述**：根据学生ID获取学生身份证信息
- **请求方法**：GET
- **完整请求路径**：`https://jyjzhfw.qiantang.gov.cn/tyba/open-api/student/idcard`

## 请求参数

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| accessToken | 接口访问凭证 | query | true | string | AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO |
| orgId | 学校的组织机构id | query | true | integer(int64) | 207 |
| id | 学生ID | query | true | integer(int64) | 20001 |

## 成功响应参数结构

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| code | 成功或异常编码 | integer(int32) |
| status | 旧接口成功、失败或异常辅助判断标记 | string |
| message | 成功或异常消息 | string |
| data | 成功或异常数据 | IdCardVO |

**IdCardVO 对象结构：**

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| sfzjh | 身份证号 | string |
| sfzjlxm | 身份证件类型码 | string |
| sfzjlxmc | 身份证件类型名称 | string |

## 成功响应示例
```json
{
    "code": 200,
    "status": "success",
    "message": "请求成功",
    "data": {
        "sfzjh": "330102201501011234",
        "sfzjlxm": "1",
        "sfzjlxmc": "居民身份证"
    }
}
```

## 未查询到数据时返回
```json
{
    "code": 200,
    "status": "success",
    "message": "请求成功",
    "data": {
        "sfzjh": "",
        "sfzjlxm": "",
        "sfzjlxmc": ""
    }
}
```

## 失败响应示例
```json
{
    "code": 500,
    "data": {},
    "message": "成功或异常消息",
    "status": "fail"
}
```

## 业务调用注意事项
- 需要同时提供 `orgId` 和 `id` 参数
- `orgId` 为学校的组织机构ID
- `id` 为学生ID
- 未查询到数据时也会返回成功状态码，但 `data` 中的字段为空字符串

## 调用示例

**NodeJs - Axios**
```javascript
var axios = require('axios');
var config = {
  method: 'get',
  url: 'https://jyjzhfw.qiantang.gov.cn/tyba/open-api/student/idcard?accessToken=AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO&orgId=207&id=20001',
  headers: {
    'X-App-Id': '1'
  }
};
axios(config)
.then(function (response) {
  console.log(JSON.stringify(response.data));
})
.catch(function (error) {
  console.log(error);
});
```

**Java - OkHttp**
```java
OkHttpClient client = new OkHttpClient().newBuilder()
  .build();
Request request = new Request.Builder()
  .url("https://jyjzhfw.qiantang.gov.cn/tyba/open-api/student/idcard?accessToken=AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO&orgId=207&id=20001")
  .method("GET", null)
  .addHeader("X-App-Id", "1")
  .build();
Response response = client.newCall(request).execute();
```
