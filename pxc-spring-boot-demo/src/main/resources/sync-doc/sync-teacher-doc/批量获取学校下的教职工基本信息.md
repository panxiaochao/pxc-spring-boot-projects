# 批量获取学校下的教职工基本信息

## 基本信息
- **接口名称**：批量获取学校下的教职工基本信息
- **接口描述**：根据学校的组织机构ID批量获取学校下的教职工基本信息
- **请求方法**：GET
- **完整请求路径**：`https://jyjzhfw.qiantang.gov.cn/tyba/open-api/teacher/list`

## 请求参数

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| accessToken | 接口访问凭证 | query | true | string | AT-16-1A-LDky-DrnnXdWh68L5wD3y2xkioxGM |
| lastSequence | 上一次去数据后台返回给客户的Seq，默认为0 | query | false | integer(int64) | 0 |
| limit | 期望获取的数据量，0 < limit <= 1000，默认为1000 | query | false | integer(int64) | 1000 |
| orgId | 学校的组织机构id | query | true | integer(int64) | 207 |

## 成功响应参数结构

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| code | 成功或异常编码 | integer(int32) |
| status | 旧接口成功、失败或异常辅助判断标记 | string |
| message | 成功或异常消息 | string |
| data | 成功或异常数据 | array[JzgVO] |

**JzgVO 对象结构：**

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| id | 教职工基本数据子类表ID | integer(int64) |
| userId | 学生的用户ID | integer(int64) |
| gh | 工号 | string |
| xm | 姓名 | string |
| xbm | 性别码 | string |
| xbmc | 性别名称 | string |
| dqztm | 当前状态码 | string |
| dqztmc | 当前状态名称 | string |
| jzglb | 教职工类别 | string |
| jzglbmc | 教职工类别名称 | string |
| lastSequence | 上一次去数据后台返回给客户的Seq，初次拉取时为0 | integer(int64) |

## 业务调用注意事项
- `limit` 参数必须满足 `0 < limit <= 1000`
- 首次拉取时 `lastSequence` 设置为 0
- 后续增量拉取时使用上一次响应中返回的 `lastSequence` 值
- `orgId` 参数为必填，需提供有效的学校组织机构ID

## 调用示例

**NodeJs - Axios**
```javascript
var axios = require('axios');
var config = {
  method: 'get',
  url: 'https://jyjzhfw.qiantang.gov.cn/tyba/open-api/teacher/list?accessToken=AT-16-1A-LDky-DrnnXdWh68L5wD3y2xkioxGM&lastSequence=0&limit=1&orgId=207',
  headers: {
    'X-App-Id': '1'
  }
};
axios(config)
.then(function (response) {
  console.log(JSON.stringify(response.data));
})
.catch(function (error) {
  console.log(error);
});
```

**Java - OkHttp**
```java

Request request = new Request.Builder()

```
