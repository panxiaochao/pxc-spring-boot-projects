# 获取教职工手机号

## 基本信息
- **接口名称**：获取教职工手机号
- **接口描述**：根据学校组织ID + 教职工ID 获取指定教职工手机号信息
- **请求方法**：GET
- **完整请求路径**：`https://jyjzhfw.qiantang.gov.cn/tyba/open-api/teacher/phone`

## 请求参数

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| accessToken | 接口访问凭证 | query | true | string | AT-17-IiZD3-NvsEhXj2Sz5D-Xqxpyd2z3kPI5 |
| orgId | 学校的组织机构id | query | true | integer(int64) | 207 |
| id | 教职工id | query | true | integer | 230822197804127848 |

## 成功响应参数结构

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| code | 成功或异常编码 | integer(int32) |
| status | 旧接口成功、失败或异常辅助判断标记 | string |
| message | 成功或异常消息 | string |
| data | 成功或异常数据 | PhoneVO |

**PhoneVO 对象结构：**

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| phone | 手机号 | string |

## 成功响应示例
```json
{
    "code": 200,
    "status": "success",
    "message": "请求成功",
    "data": {
        "phone": "17612345214"
    }
}
```

## 失败响应示例
```json
{
    "code": 500,
    "data": {},
    "message": "成功或异常消息",
    "status": "fail"
}
```

## 业务调用注意事项
- 需要同时提供 `orgId` 和 `id` 参数
- `orgId` 为学校的组织机构ID
- `id` 为教职工ID

## 调用示例

**NodeJs - Axios**
```javascript
var axios = require('axios');
var config = {
  method: 'get',
  url: 'https://jyjzhfw.qiantang.gov.cn/tyba/open-api/teacher/phone?accessToken=AT-17-IiZD3-NvsEhXj2Sz5D-Xqxpyd2z3kPI5&orgId=207&id=230822197804127848',
  headers: {
    'X-App-Id': '1'
  }
};
axios(config)
.then(function (response) {
  console.log(JSON.stringify(response.data));
})
.catch(function (error) {
  console.log(error);
});
```
