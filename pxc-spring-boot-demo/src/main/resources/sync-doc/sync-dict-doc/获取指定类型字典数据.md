# 获取指定类型字典数据

## 基本信息
- **接口名称**：获取指定类型字典数据
- **接口描述**：根据类型代码获取指定类型字典数据
- **请求方式**：GET
- **完整请求路径**：`https://jyjzhfw.qiantang.gov.cn/tyba/open-api/dict/list`

## 请求头

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| X-App-Id | 客户端 clientId | header | true | string | 1 |

## 请求参数

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| accessToken | 接口访问凭证 | query | true | string | AT-3-fDNa-D-Jb4gao58FOMB8okLmc1-iOYSR |
| dictType | 数据字典类型编码 | query | true | string | sfzjlxm |

## 成功响应参数结构

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| code | 成功或异常编码 | integer(int32) |
| status | 旧接口成功、失败或异常辅助判断标记 | string |
| message | 成功或异常消息 | string |
| data | 成功或异常数据 | array[DictCodeVO] |

**DictCodeVO 对象结构：**

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| dictTypeId | 数据字典类型数据子类表ID | integer(int64) |
| dictType | 数据字典类型 | string |
| dm | 数据字典代码集代码 | string |
| mc | 数据字典代码集代码名称 | string |

| 状态码 | 说明 |
|--------|------|
| 200 | OK |
| 其他状态码 | 参见[全局状态码](./全局状态码.md) |

## 业务调用注意事项

- `dictType` 为必填参数，必须提供有效的数据字典类型编码
- 需要确保 `accessToken` 有效且有权限访问数据字典接口
- 需要配置正确的 `X-App-Id` 请求头

## 调用示例

**NodeJs - Axios**

```javascript
var axios = require('axios');
var config = {
  method: 'get',
  url: 'https://jyjzhfw.qiantang.gov.cn/tyba/open-api/dict/list?accessToken=AT-3-fDNa-D-Jb4gao58FOMB8okLmc1-iOYSR&dictType=sfzjlxm',
  headers: {
    'X-App-Id': '1'
  }
};
axios(config)
.then(function (response) {
  console.log(JSON.stringify(response.data));
})
.catch(function (error) {
  console.log(error);
});
```

**Java - OkHttp**

```java
OkHttpClient client = new OkHttpClient().newBuilder()
  .build();
Request request = new Request.Builder()
  .url("https://jyjzhfw.qiantang.gov.cn/tyba/open-api/dict/list?accessToken=AT-3-fDNa-D-Jb4gao58FOMB8okLmc1-iOYSR&dictType=sfzjlxm")
  .method("GET", null)
  .addHeader("X-App-Id", "1")
  .build();
Response response = client.newCall(request).execute();
```
