# 获取数据字典类型列表

## 基本信息
- **接口名称**：获取数据字典类型列表
- **接口描述**：获取数据字典类型列表
- **请求方式**：GET
- **完整请求路径**：`https://jyjzhfw.qiantang.gov.cn/tyba/open-api/dict/types`

## 请求头

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| X-App-Id | 客户端 clientId | header | true | string | 1 |

## 请求参数

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| accessToken | 接口访问凭证 | query | true | string | AT-3-ewOumlQeTN7TmVufJxq-Ph1fNVnqUTeW |

## 成功响应参数结构

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| code | 成功或异常编码 | integer(int32) |
| status | 旧接口成功、失败或异常辅助判断标记 | string |
| message | 成功或异常消息 | string |
| data | 成功或异常数据 | array[DictTypeVO] |

**DictTypeVO 对象结构：**

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| id | 数据字典类型数据子类表ID | string |
| dictType | 数据字典类型 | string |
| dictName | 数据字典类型名称 | string |

## 成功响应示例

```json
{
    "code": 200,
    "status": "success",
    "message": "请求成功",
    "data": [
        {
            "id": "1",
            "dictType": "njsjzlb",
            "dictName": "年级代码"
        },
        {
            "id": "2",
            "dictType": "xbm",
            "dictName": "人员性别码"
        }
    ]
}
```

## 错误响应示例

```json
{
    "code": 500,
    "data": {},
    "message": "成功或异常消息",
    "status": "fail"
}
```

## 特殊状态码说明

| 状态码 | 说明 |
|--------|------|
| 200 | OK |
| 其他状态码 | 参见[全局状态码](./全局状态码.md) |

## 业务调用注意事项

- 需要确保 `accessToken` 有效且有权限访问数据字典接口
- 需要配置正确的 `X-App-Id` 请求头

## 调用示例

**NodeJs - Axios**

```javascript
var axios = require('axios');
var config = {
  method: 'get',
  url: 'https://jyjzhfw.qiantang.gov.cn/tyba/open-api/dict/types?accessToken=AT-3-ewOumlQeTN7TmVufJxq-Ph1fNVnqUTeW',
  headers: {
    'X-App-Id': '1'
  }
};
axios(config)
.then(function (response) {
  console.log(JSON.stringify(response.data));
})
.catch(function (error) {
  console.log(error);
});
```

**Java - OkHttp**

```java
OkHttpClient client = new OkHttpClient().newBuilder()
  .build();
Request request = new Request.Builder()
  .url("https://jyjzhfw.qiantang.gov.cn/tyba/open-api/dict/types?accessToken=AT-3-ewOumlQeTN7TmVufJxq-Ph1fNVnqUTeW")
  .method("GET", null)
  .addHeader("X-App-Id", "1")
  .build();
Response response = client.newCall(request).execute();
```
