# 钱塘区教育一体化综合服务平台 - 数据字典接口文档

## 文档前言

### 整体用途
本文档提供钱塘区教育一体化综合服务平台开放平台的数据字典接口说明，用于区校一体统筹、集约高效的教育中枢平台数据对接，实现对教育数字化改革各组织、各核心业务系统的有效支撑。

### 适用范围
本接口文档适用于需要与钱塘区教育一体化综合服务平台进行数据字典对接的第三方系统。

### 统一调用约定

#### 鉴权规则
- 所有接口请求需携带 `accessToken` 作为访问凭证
- 请求头需携带 `X-App-Id` 参数进行应用标识
- `accessToken` 需要先通过获取访问凭证接口获取

#### 获取访问凭证
- 接口文档：[获取访问凭证](../获取访问凭证.md)
- 有效期：28800 秒（8小时）

#### 请求头规范
```
X-App-Id: {应用ID}
```

#### 通用错误码说明
| 状态码 | 说明 |
|--------|------|
| 200 | 请求成功 |
| 500 | 服务器内部错误 |
| 其他状态码 | 参见[全局状态码](../全局状态码.md) |

## 附录

### 通用依赖
- 需要有效的 `accessToken` 访问凭证
- 需要配置正确的 `X-App-Id` 请求头

### 调试方法
1. 使用 Postman 或类似工具进行接口测试
2. 配置正确的请求方法、URL、请求参数和请求头
3. 检查响应状态码和返回内容

### 常见问题排查指南
- **401错误**：检查 `accessToken` 是否有效
- **403错误**：检查 `X-App-Id` 是否正确配置
- **500错误**：检查请求参数格式是否正确
