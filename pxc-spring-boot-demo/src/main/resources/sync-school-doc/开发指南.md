# 开发指南

校园大脑 • 开放平台 统一对外提供标准的业务接口，应用可在开放平台内申请相应的权限，获得授权后可通过统一的调用方式进行业务接口调用！或者与平台约定秘钥！

## API 域名

为了文档的统一管理，需要将文档中的模板地址修改为真实地址：

| 模板地址 | 真实地址 |
|----------|----------|
| `https://cas_server_url` | `https://jyjzhfw.qiantang.gov.cn` |
| `https://api_server_url` | `https://jyjzhfw.qiantang.gov.cn/tyba/open-api` |

## API 访问

在前面的认证授权对接中，接入端已经可以通过多种方式获取 accessToken，所有的业务接口再调用的时候都需要传递 accessToken。

## API 接口申请

用户需要通过创建应用，经管理员审核通过后，在应用详情页面进行接口申请。审核通过后才可调用接口。
