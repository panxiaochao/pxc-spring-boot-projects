# 批量获取学校信息

## 基本信息
- **接口名称**：批量获取学校信息
- **接口描述**：批量获取学校列表
- **请求方法**：GET
- **完整请求路径**：`https://jyjzhfw.qiantang.gov.cn/tyba/open-api/school/list`

## 请求参数

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| accessToken | 接口访问凭证 | query | true | string | AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO |
| lastSequence | 上一次去数据后台返回给客户的Seq，默认为0 | query | false | integer(int64) | 0 |
| limit | 期望获取的数据量，0 < limit <= 1000，默认为1000 | query | false | integer(int64) | 100 |

## 成功响应参数结构

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| code | 成功或异常编码 | integer(int32) |
| status | 旧接口成功、失败或异常辅助判断标记 | string |
| message | 成功或异常消息 | string |
| data | 成功或异常数据 | array[SchoolVO] |

**SchoolVO 对象结构：**

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| id | 学校基本数据子类表ID | integer(int64) |
| orgId | 学校的组织机构id | integer(int64) |
| xxbsm | 学校标识码 | string |
| xxbxlxm | 办学类型码 | string |
| xxdm | 学校代码 | string |
| xxmc | 学校名称 | string |
| xxdz | 学校地址 | string |
| xxjc | 学校简称 | string |
| xxjj | 学校简介 | string |
| xxxzm | 学校性质 | string |
| xxzt | 学校状态 | string |
| lastSequence | 上一次去数据后台返回给客户的Seq，初次拉取时为0 | integer(int64) |

| 状态码 | 说明 |

## 业务调用注意事项
- `limit` 参数必须满足 `0 < limit <= 1000`
- 首次拉取时 `lastSequence` 设置为 0
- 后续增量拉取时使用上一次响应中返回的 `lastSequence` 值

## 调用示例

**NodeJs - Axios**
```javascript
var axios = require('axios');
var config = {
  method: 'get',
  url: 'https://jyjzhfw.qiantang.gov.cn/tyba/open-api/school/list?accessToken=AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO&lastSequence=0&limit=100',
  headers: {
    'X-App-Id': '1'
  }
};
axios(config)
.then(function (response) {
  console.log(JSON.stringify(response.data));
})
.catch(function (error) {
  console.log(error);
});
```

**Java - OkHttp**
```java
OkHttpClient client = new OkHttpClient().newBuilder()
  .build();
Request request = new Request.Builder()
  .url("https://jyjzhfw.qiantang.gov.cn/tyba/open-api/school/list?accessToken=AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO&lastSequence=0&limit=100")
  .method("GET", null)
  .addHeader("X-App-Id", "1")
  .build();
Response response = client.newCall(request).execute();
```
