# 批量获取校区信息

## 基本信息
- **接口名称**：批量获取校区信息
- **接口描述**：批量获取校区列表
- **请求方法**：GET
- **完整请求路径**：`https://api_server_url/school/campus/list`

## 请求参数

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| accessToken | 接口访问凭证 | query | true | string | AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO |
| schoolId | 学校ID | query | true | integer(int64) | 11 |

## 成功响应参数结构

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| code | 成功或异常编码 | integer(int32) |
| status | 旧接口成功、失败或异常辅助判断标记 | string |
| message | 成功或异常消息 | string |
| data | 成功或异常数据 | array[CampusVO] |

**CampusVO 对象结构：**

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| id | 校区基本数据子类表ID | integer(int64) |
| orgId | 校区的组织机构id | integer(int64) |
| xqdm | 校区代码 | string |
| xqmc | 校区名称 | string |
| xqzt | 校区状态 | string |
| sfxnxq | 是否虚拟校区（0：否，1：虚拟校区） | integer(int32) |
| sfzxqm | 是否主校区码（0：主校，1：分校） | integer(int32) |
| xxdm | 学校代码 | string |
| xxmc | 学校名称 | string |

    "code": 200,
    "status": "success",
    "message": "请求成功",
    "data": [

## 失败响应示例
```json
{
    "code": 500,
    "data": {},
    "message": "成功或异常消息",
    "status": "fail"
}
```

## 业务调用注意事项
- `schoolId` 为必填参数，必须提供有效的学校ID
- 需要确保 `accessToken` 有效且有权限访问该学校的校区信息

## 调用示例

**NodeJs - Axios**
```javascript
var axios = require('axios');
var config = {
  method: 'get',
  url: 'https://api_server_url/school/campus/list?accessToken=AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO&schoolId=11',
  headers: {
    'X-App-Id': '1'
  }
};
axios(config)
.then(function (response) {
  console.log(JSON.stringify(response.data));
})
.catch(function (error) {
  console.log(error);
});
```

**Java - OkHttp**
```java
OkHttpClient client = new OkHttpClient().newBuilder()
  .build();
Request request = new Request.Builder()
  .url("https://api_server_url/school/campus/list?accessToken=AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO&schoolId=11")
  .method("GET", null)
  .addHeader("X-App-Id", "1")
  .build();
Response response = client.newCall(request).execute();
```
