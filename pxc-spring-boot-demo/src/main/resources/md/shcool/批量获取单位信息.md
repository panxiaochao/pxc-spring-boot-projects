# 批量获取单位信息

## 基本信息
- **接口名称**：批量获取单位信息
- **接口描述**：批量获取单位列表
- **请求方法**：GET
- **完整请求路径**：`https://api_server_url/unit/list`

## 请求参数

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| accessToken | 接口访问凭证 | query | true | string | AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO |
| lastSequence | 上一次去数据后台返回给客户的Seq，默认为0 | query | false | integer(int64) | 0 |
| limit | 期望获取的数据量，0 < limit <= 1000，默认为1000 | query | false | integer(int64) | 100 |

## 成功响应参数结构

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| code | 成功或异常编码 | integer(int32) |
| status | 旧接口成功、失败或异常辅助判断标记 | string |
| message | 成功或异常消息 | string |
| data | 成功或异常数据 | array[UnitVO] |

**UnitVO 对象结构：**

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| id | 学校基本数据子类表ID | integer(int64) |
| orgId | 单位的组织机构id | integer(int64) |
| dwdm | 单位代码 | string |
| dwmc | 单位名称 | string |
| dwywmc | 单位英文名称 | string |
| dwdz | 单位地址 | string |
| dwyzbm | 单位邮政编码 | string |
| dwzgbmm | 单位主管部门码 | string |
| dwjj | 单位简介 | string |
| lastSequence | 上一次去数据后台返回给客户的Seq，初次拉取时为0 | integer(int64) |

## 失败响应示例
```json
{
    "code": 500,
    "data": {},
    "message": "成功或异常消息",
    "status": "fail"
}
```

## 业务调用注意事项
- `limit` 参数必须满足 `0 < limit <= 1000`
- 首次拉取时 `lastSequence` 设置为 0
- 后续增量拉取时使用上一次响应中返回的 `lastSequence` 值

## 调用示例

**NodeJs - Axios**
```javascript
var axios = require('axios');
var config = {
  method: 'get',
  url: 'https://api_server_url/unit/list?accessToken=AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO&lastSequence=0&limit=100',
  headers: {
    'X-App-Id': '1'
  }
};
axios(config)
.then(function (response) {
  console.log(JSON.stringify(response.data));
})
.catch(function (error) {
  console.log(error);
});
```

**Java - OkHttp**
```java
OkHttpClient client = new OkHttpClient().newBuilder()
  .build();
Request request = new Request.Builder()
  .url("https://api_server_url/unit/list?accessToken=AT-10-R6Bl-dFf8itd6BM-pdSMzKRTR-kTmlpO&lastSequence=0&limit=100")
  .method("GET", null)
  .addHeader("X-App-Id", "1")
  .build();
Response response = client.newCall(request).execute();
```
