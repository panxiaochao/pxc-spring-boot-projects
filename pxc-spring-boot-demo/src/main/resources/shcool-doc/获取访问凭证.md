# 获取访问凭证

## 基本信息
- **接口名称**：获取访问凭证
- **接口描述**：根据应用 client_id 和 client_secret 获取 access_token
- **请求方式**：POST
- **完整请求路径**：`https://jyjzhfw.qiantang.gov.cn/oauth2.0/accessToken`

## 请求参数

| 参数名称 | 参数说明 | 请求类型 | 是否必须 | 数据类型 | 示例值 |
|----------|----------|----------|----------|----------|--------|
| client_id | 应用审核通过后返回的client_id | query | true | string | yourclient |
| client_secret | 应用审核通过后返回的client_secret | query | true | string | yoursecret |
| grant_type | 授权类型常量 client_credentials | query | true | string | client_credentials |

## 成功响应参数结构

| 参数名称 | 参数说明 | 类型 |
|----------|----------|------|
| access_token | 接口访问令牌 access_token | string |
| token_type | 令牌类型：bearer | string |
| expires_in | 令牌有效期 | integer(int32) |

## 成功响应示例
```json
{
    "access_token": "AT-3-rX4WfOiCgiF6qMNt52PfqDaQj-F4I9LK",
    "token_type": "bearer",
    "expires_in": 28800
}
```

## 错误响应示例
```json
{
    "timestamp": 1660987198227,
    "status": 401,
    "error": "Unauthorized",
    "message": "No message available",
    "path": "/oauth2.0/accessToken"
}
```

## 业务调用注意事项
- `client_id` 和 `client_secret` 需在应用审核通过后获取
- `grant_type` 必须固定为 `client_credentials`
- `access_token` 有效期为 28800 秒（8小时）
- 请妥善保管 `client_secret`，切勿泄露

## 调用示例

**JavaScript - Fetch 示例**
```javascript
var myHeaders = new Headers();
var requestOptions = {
  method: 'GET',
  headers: myHeaders,
  redirect: 'follow'
};
fetch("https://jyjzhfw.qiantang.gov.cn/oauth2.0/accessToken?grant_type=client_credentials&client_id=yourclient&client_secret=yoursecret", requestOptions)
  .then(response => response.text())
  .then(result => console.log(result))
  .catch(error => console.log('error', error));
```

**Java - OkHttp 示例**
```java
OkHttpClient client = new OkHttpClient().newBuilder()
  .build();
Request request = new Request.Builder()
  .url("https://jyjzhfw.qiantang.gov.cn/oauth2.0/accessToken?grant_type=client_credentials&client_id=yourclient&client_secret=yoursecret")
  .method("GET", null)
  .build();
Response response = client.newCall(request).execute();
```
